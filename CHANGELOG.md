# Changelog

All notable changes to **Voogle Route** are documented here.  
Version numbers follow [Semantic Versioning](https://semver.org/) where practical.

## [0.10.0] - 2026-06-02

### Added

- On-ground route line for **Voogle Maps** destinations (`customDestination`)
- Turn-by-turn HUD and intersection arrows while driving
- **VOOGLE ROUTE** panel with **ROUTE ON/OFF** and auto-walk
- Localization for all **22** Big Ambitions interface languages
- `latest.json` manifest for future auto-update support

### Changed

- Renamed from **On-Map GPS** (`OnMapGps.dll`) to **Voogle Route** (`VoogleRoute.dll`)
- MelonLoader preference category: `VoogleRoute`

### Removed

- Legacy mod id `OnMapGps` — remove `OnMapGps.dll` from `Mods/` when upgrading
