# Visual screenshot baselines

PNG baselines for VoogleRoute UI regression checks.

## Folders

| Folder | Purpose |
|--------|---------|
| `baselines/` | Committed reference images (add after first approved capture) |
| `actual/` | Latest captures from the in-game harness (gitignored) |
| `diff/` | Pixel diffs generated by `compare-visual.ps1` (gitignored) |

## File naming

```
{scenario-id}.png
```

Example: `route-action-370.png`

## Workflow

1. `install-visual-saves.ps1` + `install-visual-test-assets.ps1`
2. `prepare-visual-request.ps1 -ScenarioId <id>`
3. Load the matching save in-game
4. Harness writes PNG to `actual/` (or path in request)
5. `compare-visual.ps1 -ScenarioId <id>`
6. If correct, copy `actual/<id>.png` → `baselines/<id>.png` and commit
