# Visual screenshot baselines

PNG baselines for VoogleRoute UI regression checks.

## Folders

| Folder | Purpose |
|--------|---------|
| `baselines/` | Committed reference images (add after first approved capture) |
| `actual/` | Latest manually captured screenshots (gitignored) |
| `diff/` | Pixel diffs generated by `compare-visual.ps1` (gitignored) |

## File naming

```
{scenario-id}.png
```

Example: `route-action-370.png`

## Workflow

1. Optionally install the matching fixture with `install-visual-saves.ps1`.
2. Load the matching save and prepare the documented UI state manually.
3. Capture the target at the reference resolution and save it as `actual/<scenario-id>.png`.
4. Run `compare-visual.ps1 -ScenarioId <id>`.
5. If correct, copy `actual/<id>.png` to `baselines/<id>.png` and commit.

The old request-file harness was removed from the public mod because it polled the filesystem every frame.
