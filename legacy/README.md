# MelonLoader builds (EA 0.10) — archived

Versions **0.10.0** and **0.10.1** targeted Big Ambitions EA **0.10** with **MelonLoader** (`Big Ambitions/Mods/VoogleRoute.dll`).

That codebase lived in this repository before the **0.11 SDK** rewrite. Source and release DLLs remain available via git history and GitHub release tags:

- [v0.10.1](https://github.com/capisoft-lib/BigAmbitions_VoogleRoute/releases/tag/v0.10.1)
- [v0.10.0](https://github.com/capisoft-lib/BigAmbitions_VoogleRoute/releases/tag/v0.10.0)

**Do not use MelonLoader builds on EA 0.11.** Subscribe to the Steam Workshop item for the current mod.
